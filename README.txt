MELTY STUDY NOTE — iPhone用Webアプリ

内容
- index.html: アプリ本体
- manifest.webmanifest: ホーム画面追加用の設定
- sw.js: オフライン起動用キャッシュ
- icon-192.png / icon-512.png: アプリアイコン

重要：iPhoneでホーム画面アプリとしてインストールするには、HTTPSで公開する必要があります。
HTMLファイルを「ファイル」アプリから開くだけでは、PWAとしてインストールできません。

公開して使う手順（無料で始める例）
1. GitHubにログインして、新しい公開リポジトリを作成します（例: melty-study）。
2. このZIPの中身をすべてリポジトリの一番上にアップロードします。
3. リポジトリの Settings → Pages → Build and deployment で、Deploy from a branch / main / /(root) を選び保存します。
4. 公開URLが表示されたら、iPhoneのSafariでそのURLを開きます。
5. Safariの共有ボタン →「ホーム画面に追加」→「追加」。
6. 追加されたアイコンから起動します。初回アクセス後はオフライン起動に対応します。

保存について
- ノート本文、ノート一覧、画像データ、チェックリストはブラウザのlocalStorageに端末内保存します。サーバーには送信しません。
- SafariのWebサイトデータを消去したり、ブラウザのデータが消えたりするとノートも消える可能性があります。定期的に「JSON書き出し」でバックアップしてください。
- JSON書き出しはバックアップ用です。現状、JSONの読み込み/復元ボタンはありません。
- 画像は1枚5MBまで。端末の空き容量によって保存できる量は変わります。
- オフラインキャッシュは初回のオンラインアクセス後に有効になります。

注意：これはApp Store配布用のネイティブiOSアプリ(.ipa)ではなく、ホーム画面から独立して起動できるPWAです。
